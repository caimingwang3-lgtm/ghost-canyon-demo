# 幽影峡谷：裂隙巫妖

**横版动作关卡与战斗策划作品原型**  
作品方向与迭代决策：本人｜网页原型实现：AI 辅助开发｜版本：2026.10

## 作品简介

本作品通过一段可试玩的横版动作流程，展示如何用教学遭遇引入操作，再通过精英战和多阶段隐藏首领检验玩家对招式的理解。核心体验是“观察预警、选择应对、抓住收招反击”。

### 推荐试玩路线

1. 从首页选择 **完整试炼**，体验热身、双威胁、检查点与幽影守卫精英战。
2. 精英战后观看剧情；可按 **Space** 跳过剧情，再选择是否挑战裂隙巫妖。
3. 时间有限时选择 **直达 Boss**。想检查具体关卡或招式时，使用 **策划模式** 选择关卡、阶段和承伤规则。

完整流程适合体验关卡节奏；直达 Boss 与策划模式适合快速查看战斗设计。

## Windows 启动

1. 将作品包解压到普通文件夹。
2. 已安装 Node.js 或 Python 的 Windows 电脑上双击 `启动Demo.bat`。
3. 浏览器打开后保持命令窗口运行；试玩结束按 `Ctrl+C` 停止服务。

本地试玩不需要 npm 安装或网络连接；启动器优先使用 Node.js，无 Node.js 时尝试 Python 自带的 HTTP 服务。若无法自动打开，在作品目录运行 `node server.cjs`，或运行 `py -m http.server 4173 --bind 127.0.0.1`，再访问 `http://127.0.0.1:4173/`。不要直接双击 HTML 文件。

> `127.0.0.1` 是本机地址，只能在运行 Demo 的电脑上访问。若需远程面试官在线试玩，应先部署到可公开访问的静态网站，并在另一台设备上验证链接。

## 设计重点

- **渐进式关卡节奏**：单体教学 → 近战与远程组合 → 检查点 → 精英遭遇 → 隐藏首领。
- **多种攻防选择**：格挡消耗耐力；弹反要求时机、距离与朝向；闪避有冷却；攻击存在前摇、有效帧与收招。
- **精英与首领差异化**：幽影守卫使用骑士近战招式；裂隙巫妖使用独立绘制的骷髅法师外观，以及灵魂震爆、追魂冥火、幽魂换位和亡魂印爆。
- **剧情分支**：精英战揭示巫妖的幕后身份，玩家可以选择是否继续挑战。
- **策划测试入口**：选择热身、双威胁、检查点、精英或巫妖阶段，可切换承伤/无敌，并使用阶段跳转快捷键。
- **本地体验记录**：记录攻防表现并提供试玩问卷；数据保存在本机浏览器，不上传网络。
