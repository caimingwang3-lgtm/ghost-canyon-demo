# 迭代证据

这里是对应《测试迭代记录》的实测截图。每张都标了"改前是什么问题"。

| 文件 | 说明 |
|---|---|
| 01_亡魂凝视_补光束后.png | 「亡魂射线亮一下就掉血」→ 开火时**根本没画光束**。这是补上三层光束后的实测画面，能看到从巫妖头部射向落点的光束，玩家身上同时跳出 -20 |
| 02_獄火華_换真实火焰序列帧.png | 火柱原来是两个纯色半透明矩形。换成 CC0 授权（素材来源.md 有出处）的 16 帧火焰序列后 |
| 03_手机端_策划模式可用.png | 手机上策划模式的面板超出屏幕却滑不动、够不到「开始测试」。修好后实测：按钮可见、面板可滚动 |
| 04_骑士图压缩_左原图_右压缩.png | 手机加载慢的主因是 13 张骑士图共 12.6MB（像素风却存成全彩 PNG）。转 256 色调色板后降到 2.6MB，左原图右压缩，肉眼无差别。平均色差 6.7/255、明显坏点 0.46% |

截图都是开发过程中在无头浏览器里实际跑出来的画面（手机那张用了移动端模拟）。
