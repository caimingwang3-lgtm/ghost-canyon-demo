# Cathedral Sprint · 月下疾走

哥特中世纪像素风屋顶跑酷，可安装、可离线的网页应用（PWA）。
月夜教堂屋脊之上，黑羽少女在血色垂帘与石像追杀间疾走，撞上玫瑰彩窗迎来加速浪潮。

## 玩法

| 操作 | 按键 | 触屏 |
| --- | --- | --- |
| 跳跃 / 二段跳 | `↑` / `空格` / `W` | 点屏幕上半区 |
| 滑铲 / 空中下压 | `↓` / `S` | 点屏幕下半区 |
| 冲刺碎障 | `Shift` / `D` / `→` | 右下角冲刺键 |

- 滑铲穿过低垂石像横梁与血色垂帘光门。
- 跳过地面火焰弹与屋顶缺口；金色圣光栅栏、落地巨石像要二段跳（或冲刺撞碎）。
- 火焰弹与巨石像可被冲刺撞碎并额外加分。
- 周期性的玫瑰彩窗是清场加速、安全冲分的浪潮。

## 部署到 GitHub Pages（无需后端）

1. 把本目录里的**全部文件**（`index.html`、`manifest.webmanifest`、`sw.js`、`icons/`）传到一个 GitHub 仓库根目录（或 `/docs`、`gh-pages` 分支）。
2. 仓库 **Settings → Pages**，Source 选择对应分支与目录，保存。
3. 等待约 1 分钟，打开给出的 `https://<用户名>.github.io/<仓库名>/` 即可游玩。

## 安装为应用（断网也能玩）

- 电脑 Chrome / Edge：打开页面后点地址栏右侧的**安装**图标，或菜单 →「安装“月下疾走”」。
- 安卓 Chrome：菜单 →「添加到主屏幕 / 安装应用」。
- iPhone / iPad：用 **Safari** 打开，分享按钮 →「添加到主屏幕」。
- 安装后全屏横屏运行、带独立图标，首次打开后断网也能玩。

## 文件结构

```
index.html              游戏本体（所有画面、像素角色、程序配乐均已内联，本身就是单文件）
manifest.webmanifest    应用名、图标、主题色、全屏横屏等安装信息
sw.js                   Service Worker，负责把全部资源缓存到本地以离线运行
icons/icon-192.png      应用图标
icons/icon-512.png      应用图标（含 maskable 适配）
```

> 说明：直接双击 `index.html`（file://）也能完整游玩；但“安装到桌面 / 离线缓存”必须通过 https（如 GitHub Pages）或 localhost 访问，本地双击时浏览器会自动跳过这一步。
