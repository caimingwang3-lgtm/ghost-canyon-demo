# 《墨影疾行：断桥试炼》

**类型：** 横版动作跑酷关卡原型 / 个人练习  
**版本：** 内容扩展版｜2026.10  
**试玩入口：** 打开 `index.html`；单文件 HTML 加资源即可本地游玩，无需安装依赖。  
**设计资料：** 本说明、`关卡事件表.csv`、`战斗数值表.csv`、`简历与投递.md` 与 `素材来源.md`。

## 玩法概览

本版把原有的障碍跑酷和 Boss 对决扩成一条分段追击路线：先教学跳跃、下滑，再加入会读前摇突刺的断桥守卒、会瞄准发射纸鸢弹的纸鸢射手，之后出现双敌人编组、能量补给和更密集的机关组合，最终挑战纸鸢武者。关卡在距离 14,500 左右进入 Boss 战；跑酷段约 60 秒，连同 Boss 战的整体游玩时长目标约 90–120 秒。以上是设计目标，实际时长和难度仍须试玩验证。

### 操作

| 输入 | 效果 | 玩法反馈 |
|---|---|---|
| ↑ / W / 空格 | 跳跃 | 越过地面尖刺，也可躲过守卒突刺或纸鸢弹 |
| ↓ / S | 下滑 | 躲过头顶横刃、守卒突刺和低位纸鸢弹 |
| J / X | 发射追星镖 | 命中小怪造成伤害；击倒小怪后掉落能量球 |
| K / Z | 释放破阵奥义 | 消耗 100 能量，清除小怪与纸鸢弹，并对 Boss 造成伤害 |
| Esc | 暂停 | 暂停 / 继续 |

窄屏可用画面下方的触控按钮；声音可关闭。

## 小怪机制

- **断桥守卒（近战）：** 接近玩家后用红色武器提示蓄力约 0.68 秒，再向前突刺。玩家可跳跃、下滑闪避，也可用飞镖打断；守卒需要命中两次才会被击倒。
- **纸鸢射手（远程）：** 接近画面中段时显示红色瞄准线，约 0.82 秒后发射低位纸鸢弹。玩家可以跳跃或下滑躲开；射手一次锁定只发射一枚弹丸。
- **双人编组：** 守卒与射手错开出现，形成“处理近身突刺 / 同时观察远程预警”的优先级判断。奥义可清除场上小怪和已发射的纸鸢弹。
- **击倒反馈：** 守卒和射手被击倒后分别掉落 +18 / +16 能量的青色能量球，球体有浮动、发光及数值提示，接触后吸收。

## 能量与奥义

发射飞镖本身不再免费增加能量，避免站在原地连发就把奥义充满。当前可获得能量的方式：

| 行为 | 能量 |
|---|---:|
| 飞镖命中小怪 | +5 |
| 击倒守卒 / 射手后吸收能量球 | +18 / +16 |
| 关卡预置补给球 | +20 |
| 成功躲过尖刺 / 横刃 | +10 |
| 成功躲过守卒突刺 / 纸鸢弹 | +8 / +6 |
| 成功躲过 Boss 招式 | +18 |
| 飞镖命中 Boss 收招窗口 | +8 |

能量上限 100；受击扣除 12。奥义消耗全部能量，清理小怪并对 Boss 造成 34 点伤害。能量、伤害和时间目前都是可调整的首轮假设。

## 关卡节奏配置

关卡事件按跑动距离触发，基准速度 240 px/s，配置直接对应 `index.html` 中的 `events` 数组。

| 距离 | 内容 / 事件 | 设计目的 |
|---:|---|---|
| 550–1,050 | 尖刺、头顶横刃 | 分别教学跳跃、下滑 |
| 1,550–3,600 | 守卒、尖刺、射手、横刃 | 先教突刺，再教远程预警 |
| 4,300–5,750 | 能量球、双人小队、尖刺 | 演示击倒掉落，并开始敌人组合 |
| 6,500–9,950 | 守卒、横刃、射手、双人小队、补给 | 练习目标优先级和资源收集 |
| 10,600–13,800 | 尖刺、双人小队、横刃、守卒、补给 | 提升组合压力，并在 Boss 前提供资源机会 |
| 14,500 | 纸鸢武者 | 进入 Boss 两招交替与硬直输出 |

## Boss 战与用例

纸鸢武者沿用原型的两种交替攻击：地面横斩需要跳跃，空中斩需要下滑；躲避成功后出现收招窗口，可用飞镖或奥义输出。手工验证时可检查：

1. 两类小怪的前摇、伤害、命中与被击倒反馈是否清楚。
2. 小怪掉球、关卡补给球是否能接触收集，能量是否正确受限于 100。
3. 连续发射飞镖不会凭空快速充满奥义；命中、躲避和拾取分别按配置给能量。
4. 奥义能击退小怪、清除敌方弹丸，并能对 Boss 正确扣血。
5. 完整流程、死亡重试、暂停、音效开关及触控 / 键盘操作。

这些项目是待执行的验证清单，不代表已取得测试数据。下一轮应记录首次受击位置、小怪招式躲避率、能量球拾取率、奥义释放时机和完整通关时间；每轮先改一个主要变量。

## 素材与项目边界

玩家使用 OpenGameArt 上的 CC0 **Ninja [Animated]**；音乐为 OpenGameArt 的 CC0 **Project Utopia**；音效使用 Kenney **Interface Sounds** CC0。新增守卒和射手选用 Kenney **Roguelike Characters** 角色图集中的像素角色，图集 16×16 px，放大绘制以匹配原有小人比例。许可与链接见 `素材来源.md`，Kenney CC0 许可文件随包附带。

这是个人关卡策划练习与浏览器原型，不是商业项目。数值和 90–120 秒目标均尚待更多试玩验证。
