# 《墨影疾行：断桥试炼》简历与投递说明

## 可用项目条目

**《墨影疾行：断桥试炼》横版动作关卡与战斗原型｜个人练习｜2026.10**

- 将单段跑酷扩展为约 90–120 秒的多段关卡设计：由障碍教学、近远程小怪、双人编组、能量补给逐步推进至 Boss；该时长为设计目标，尚待实际试玩验证。
- 设计断桥守卒的红色蓄力 / 突刺与纸鸢射手的瞄准 / 低位弹丸机制，并配置跳跃、下滑、飞镖打断和奥义清场等应对方式。
- 加入小怪击倒掉落能量球、关卡定点补给和受击扣能量；调整能量来源，避免单纯连续发射就充满奥义。
- 该作品使用 HTML Canvas / JavaScript 实现浏览器原型；整理距离触发的关卡事件配置与初版战斗数值。
- 使用 Kenney CC0 像素角色区分近战和远程敌人，保留素材来源及授权记录。

**作品文件：** 本文件与 `作品说明.md`、`素材来源.md`、`index.html` 及 `assets/` 资源一起打包。当前无公开试玩链接，不要把本机地址写进简历。

## 讲解建议

按“关卡问题 → 小怪差异 → 玩家应对 → 能量循环 → 下一轮验证”讲解。明确区分已经实现的规则与待验证的假设；不要把计划的测试说成已完成测试，也不要宣称原型由本人独立编程实现。
